# ExtendedCommonUI - Unreal Engine Plugin

This is the **ExtendedCommonUI** plugin, built on top of Unreal Engine's **Common UI** plugin to provide enhanced UI functionality and extended features for scalable user interfaces.

## About ExtendedCommonUI

ExtendedCommonUI extends the capabilities of Epic Games' Common UI framework, providing additional components, utilities, and enhanced functionality for creating sophisticated user interfaces. It offers:

- **Enhanced Common UI Components**: Extended versions of Common UI widgets with additional features
- **Advanced List Management**: Hierarchical and complex list widget implementations
- **Extended Action System**: Enhanced input action handling and routing
- **Messaging Framework**: Advanced dialog and messaging system
- **Layout Extensions**: Enhanced game layout and widget management
- **Analog Cursor Support**: Extended cursor functionality for gamepad navigation

## Foundation

This plugin is built on top of **Unreal Engine's Common UI** plugin:
- **Base Framework**: Unreal Engine's CommonUI plugin
- **Enhanced Functionality**: Additional features and extended capabilities
- **Scalable Architecture**: Built for multi-platform and responsive design
- **Input System Integration**: Enhanced input handling and action routing
